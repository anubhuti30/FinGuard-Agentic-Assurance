# FinGuard — Agentic Financial Assurance

> A portfolio fork exploring controls for agentic financial actions.

## Project provenance

This repository is a fork of [EXORYN Agentic Assurance](https://github.com/ASanchezT85/agentic-assurance).

The upstream implementation and its existing features are not original work by this repository's maintainer. The upstream project is licensed under MIT. See `LICENSE` and preserve the original copyright and license notices.

Any additional contributions will be documented separately, with their implementation and validation status stated accurately.

## Scope

The upstream project explores authorization, idempotency, financial usage limits, and atomic reservations for agentic financial actions. This fork is for learning and portfolio exploration; it is not a security certification or a production trading system.
